# 已知限制（投稿前必读）

本文件逐条列出当前实现**没有做到**的事。在论文中引用本仓库结果时，
应据此如实描述，不得超出以下范围。

## 1. 金标准的性质

- core 级 Gleason / ISUP 是**由 SICAPv2 像素级掩码按面积规则推导**得到的
  （`src/core/gleason_rules.py`），**不是**病理医师出具的病例级报告。
- 面积规则与医师判读不等价：医师会综合腺体结构形态（筛状、融合、乳头状等），
  而本规则只看面积占比。
- SICAPv2 官方发布渠道提供病例级标注表（含 global Gleason score）。
  **建议在投稿前获取该表与本仓库推导结果交叉核对**；若两者不一致，
  应以官方病例级标注作为金标准。
- 为使结论稳健，**主评价指标应使用像素级 Dice / IoU**（不依赖推导规则）；
  core 级评分一致性应作为次要指标，并在文中注明推导方式。

## 2. 数据规模与泛化性

- 仅使用 SICAPv2 的 244 个 core（原数据集含 18,783 张 10× 图像，本仓库未使用全量）。
- 单中心、单扫描来源、单染色流程；**没有外部验证集**，跨中心泛化性未知。
- 类别极度不平衡：GG5 占 2.7%、NC 占 4.5%，稀有类的指标方差会很大。

## 3. 实验设计

- 单次 train/val 划分（默认随机 70/30，seed=42），**未做交叉验证**。
  报告指标应说明为单次划分结果。
- 未做统计显著性检验（指标未给出跨折方差）。
- 未进行多专家一致性（ICC / Kappa）评估——数据集中不存在多人标注。

## 4. 标注本身的限制

- 掩码值 1 的官方语义未确认，已归入背景（占 1.5% 像素）。
- 掩码为区域级标注，未区分独立腺体，**不支持"细胞计数"或"实例计数"类结论**。
- 部分 core 的图像与掩码尺寸不完全一致（如 5632×5120），
  数据准备阶段按较小尺寸裁剪，边缘少量像素会被丢弃。

## 5. 未纳入本仓库的旧代码

以下内容存在于原始工作目录但**未纳入本仓库**，其产出结果不可引用：

- 基于随机数的细胞检测回退逻辑、随机 Gleason 区域生成
- 由模型输出反推"金标准"再评价模型的统计分析路径
- 用公式 + 随机波动模拟的训练曲线
- 在合成圆点图像上训练的早期 CNN 原型（见 `legacy/README.md`）
- 宣称 U-Net+ResNet34、1000 张全切片、5 折交叉验证、多专家 ICC 0.85–0.92
  的方法学文档，与任何现存代码和数据均不对应

## 6. 临床适用性

- 未进行任何临床验证，**不是医疗器械**。
- 未评估在真实临床工作流中的失败模式（伪影、烧灼边缘、切片折叠等）。
- 推理结果为像素级概率输出，未做不确定性估计或拒答机制。
